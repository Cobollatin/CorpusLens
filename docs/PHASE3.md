# Phase 3 offline implementation

The local snapshot command reads owner-provided EPUBs in `data/raw/` and writes ignored snapshots to `data/snapshots/`. Use absolute paths with `--epub`; no discovery or download is required. The committed manifest records the source URI and checksum, verse reconciliation, coverage, layer counts, and Batch planning figures.

The 31,102 figure is a conventional verse-slot baseline, not a claim that every edition prints 31,102 verse texts. English has 31,078 nonempty verse texts and 24 listed absent slots. Spanish has 31,062 and 40 absent slots. Mark 16:9–20 and John 7:53 are terminal slots absent from EPUB navigation. John 8:1–11 are note-only markers. The remaining Spanish omissions are edition-specific absent verse slots. The manifest lists every ID explicitly and the snapshot audit covers every extracted text character.

`batch-export --lang E|S` writes deterministic UTF-8 JSONL files under ignored `data/batch/`. Each shard holds fewer than 50,000 requests and fewer than 200 MB. The request input is the complete chunk embedding input, with `text-embedding-3-large`, 1024 dimensions, and float output. The estimate is `ceil(UTF-8 bytes / 4)` per request, priced at $0.065 per million estimated input tokens. This is a documented approximation, not a tokenizer count or observed charge. Review actual provider token usage before committing spend.

After authorizing an Oracle environment, `schema-migrate [--ivf]` applies the schema and one vector index choice, and `revision-stage --lang E|S` inserts the audited snapshot. Both require `CORPUSLENS_ALLOW_ORACLE_CONNECT=yes`. The migration runner is intended for a fresh schema; it does not yet maintain a migration history or support reruns.

`batch-submit --lang E|S` requires `CORPUSLENS_ALLOW_BATCH_SUBMIT=yes` and `OPENAI_API_KEY` in the process environment. It checks the default $5 estimate cap before submission and records job state in ignored `data/batch/<lang>/ingest-jobs.json`; it also writes `ingest_job` rows when Oracle connection is explicitly enabled. `batch-status --lang E|S` polls recorded jobs. `batch-import --lang E|S --output <combined-results.jsonl>` requires all jobs complete and a staged Oracle revision, reconciles every custom ID and finite 1024-dimensional vector, inserts vectors, then activates only after coverage and completeness gates pass. No Batch submission, Oracle connection, OCI provisioning, or index measurement was performed in this offline phase.

Oracle settings can come from environment (`CORPUSLENS_ORACLE_CONNECTION_STRING`, `CORPUSLENS_ORACLE_WALLET_PATH`, `TNS_ADMIN`) or .NET configuration/user secrets (`ConnectionStrings:Oracle`, `Oracle:WalletPath`, `Oracle:TnsAdmin`). The wallet directories are validated at startup when Oracle is configured. `Oracle:KeepAliveHours` defaults to 24. The embedded schema runner applies `001_schema.sql`, `002_text.sql`, then HNSW or the separate IVF fallback. Choose the ANN index only after checking the actual ADB version, vector-pool capacity, build time, memory, and query recall. Those measurements and restore testing require a later authorized Oracle environment.
